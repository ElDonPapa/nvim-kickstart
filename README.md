# My Neovim config

My personal Neovim configuration, based on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim).

## Install

Requires Neovim 0.12+, plus `git`, `make`, `unzip`, a C compiler, `ripgrep`,
the `tree-sitter` CLI and `node`/`npm`.

```sh
git clone git@github.com:ElDonPapa/nvim-kickstart.git ~/.config/nvim
nvim
```

Plugins, language servers and formatters install themselves on first launch.
